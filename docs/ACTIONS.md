## The `edit` action

Run a batch of operations on a specific open drawing. First call get_drawing_info and verify the drawing name. Pass its target and new_edit_request_id as target and request_id. Use the target from the reads used to prepare this edit. A changed session or active drawing stops the edit. The drawing operations share one transaction. dry_run aborts that transaction after validation and is not recorded under its request_id, so the same ID can be used for the real edit. File outputs run after commit. Editing requires permission for the target drawing. If the response is interrupted, check get_edit_status with the original target and request_id; if retryable is true, resend with the same parameters and request ID. If state is 'error' and retryable is false or absent, inspect the drawing and receipt before attempting another edit.
